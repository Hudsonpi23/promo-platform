# Análise do Concorrente: Lobão das Promoções

> Análise feita em 04/04/2026 com base em prints reais das redes do Lobão.

---

## 1. Perfil

- **Nome:** Lobão das Promoções
- **ML Social:** mercadolivre.com.br/social/agenciarice (32.172 seguidores)
- **Canais:** WhatsApp, Telegram, X (Twitter) — NÃO usa Instagram
- **Velocidade:** 1 minuto entre posts em diferentes canais
- **Volume:** Alto — dezenas de produtos por dia

## 2. Padrão dos Posts

### Formato usado:
```
ESSE É DE CRIA

👟 Tenis Oakley Flak 365 II Lite (3 cores)
💰 De R$ 749 por R$ 296 no Pix

· Resgate os cupons: M3L1V1P12X + DENNISDJ10 + HOJETEMPROMO + CUPOMPRAMODA + Selecione Pix

Loja oficial Oakley no ML
👉 https://meli.la/1LLQGxF
```

### Problemas identificados:
1. Lista 4+ códigos de cupom, mas **só 1 funciona por compra**
2. O cliente perde tempo digitando códigos desnecessários
3. Cupons são **públicos** (disponíveis em mercadolivre.com.br/cupons/)
4. Apresentados como "exclusivos" — gera expectativa falsa
5. Não explica que descontos são compostos, não somados

### Fluxo Passo a Passo
```
1. Acessa mercadolivre.com.br/cupons/
2. Filtra por categoria (ex: Calçados, Roupas e Bolsas)
3. Vê múltiplos cupons MODA FULL (10%, 15%, 10%, 25%, 30%...)
4. Clica em "Conferir produtos" em cada cupom
   → Vê quais produtos são elegíveis
5. Encontra um produto que aparece em múltiplos cupons
   → Ex: Tênis Oakley é MODA FULL → encaixa em 3+ cupons
6. Resgata cada cupom (clica "Aplicar")
   → Cada um gera um código ou fica automático na conta dele
7. Posta o produto listando TODOS os códigos de cupom
   → "Resgate os cupons: X + Y + Z + W"
8. Dispara para WhatsApp + Telegram + X simultaneamente
```

### O Truque
- Ele sabe que **SÓ 1 CUPOM VALE POR COMPRA**
- Mas lista 3-4 códigos para o seguidor achar que ganha mais
- O seguidor testa cada código, aplica o melhor, e acha que "hackeou" o sistema
- Enquanto isso, existem cupons de **25% e 30%** na mesma página que ele ignora no post

### Evidências
- Posts com 1 minuto de diferença entre canais (WhatsApp 1h27, X 1h26)
- Variação de cupons por produto (4 em Moda, 1 em Beleza, 0 em Shopee)
- Padrão consistente de formatação
- Cupons listados batem com a página pública de cupons ML por categoria

## 4. Nosso Diferencial vs Lobão

| Lobão | Nós |

| 4 cupons (só 1 vale) | Informa: "1 cupom por compra" |

| Inclui frete no post | Sem frete (varia por cliente) |

| 32k seguidores passivos | Seguidores fiéis e informados |

## 5. O que Aprender com o Lobão

### Pontos fortes (copiar):
- Velocidade de postagem (automação)
- Multi-canal simultâneo
- Monitoramento de cupons diário
- Alto volume de posts

### Pontos fracos (explorar):
- Falta de transparência com cupons
- Não educa o seguidor
- Posts genéricos sem personalidade
- Não usa Instagram (oportunidade para nós)
